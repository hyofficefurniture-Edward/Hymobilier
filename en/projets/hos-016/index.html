Radisson Collection Lingang Shanghai: a China hospitality reference

The group Radisson Collection document is identified with Lingang, Shanghai, China, using the property identity and operator information. The reference provides a basis for separating guestroom furniture from serviced-apartment requirements in a new procurement brief.

Exterior view cropped from the group document to identify Radisson Collection Lingang Shanghai. Building performance is not a certification of the furniture.

Property identity checked in Lingang, Shanghai

The identity visible in the group document has been checked against the official Radisson Collection Lingang Shanghai property page. The operator describes guest rooms, suites and serviced apartments. This establishes identity and accommodation types; the items actually supplied by a vendor require a separate supply schedule.

Guestrooms: create a room-type furniture schedule

For a new hotel, map beds, bedside units, desks, luggage storage and wardrobes onto each room plan. Check circulation, door openings, outlets and fixed-joinery interfaces. An operator’s published room count must not be treated as a supplier’s delivered furniture quantity.

Serviced apartments: keep a separate item list

For a new extended-stay programme, separate sleeping, dining, storage and equipment areas. Define furniture, appliances and connection responsibilities before pricing. A hotel or apartment image does not add kitchens, appliances or technical installation to a furniture offer.

Approve the next order through drawings and samples

Request an item schedule by space with dimensions, finishes, quantities and sample references. Confirm access, packing and installation responsibilities for your destination. The Chinese project provides context; tests, transport conditions and local services for the next order need their own confirmation.
