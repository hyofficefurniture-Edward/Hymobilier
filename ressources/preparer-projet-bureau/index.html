GUIDE PRATIQUE

Les informations utiles pour un projet de bureau

Un dossier d’implantation pour préciser postes, réunions, accueil et rangement.

Le dossier doit expliquer qui utilise les espaces, quels équipements sont nécessaires et comment le mobilier s’intègre au plan.

Décrire les usages

Indiquez l’effectif, les postes fixes ou partagés, la capacité des réunions et les besoins de réception.

Préciser les interfaces

Les passages de câbles, écrans et équipements doivent être repérés. Vérifiez les accès et le rangement.

Préparer les spécifications

Définissez les dimensions souhaitées, les finitions et les documents nécessaires. Les performances se confirment pour les modèles sélectionnés.
