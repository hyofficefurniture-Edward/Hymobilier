Comptoir de réception JIANGNAN

Comptoir JIANGNAN QT-03C24 : confirmer dimensions personnalisées, niveaux de travail, rangement et accès avant la commande.

Visuels de catalogue ; précisez composition et accessoires dans la liste de commande. Ce ne sont pas des photos de livraison.

Identifier la configuration JIANGNAN

La page fabricant identifie le code QT-03C24 dans la série JIANGNAN et indique des dimensions à personnaliser. Utilisez ce code pour demander le dessin correspondant ; ne transposez pas les dimensions d’un autre comptoir montré dans la famille.

Préciser les niveaux et le rangement

La vue principale montre une façade et un niveau supérieur distinct. Définissez surface de travail, échange de documents et ouverture des rangements sur le dessin retenu. Les équipements, le nombre de postes et les passages de câbles doivent être listés séparément.

Valider les échantillons et la liste de pièces

Comparez surfaces, corps du meuble et raccords sur échantillons et dessins approuvés. Listez séparément chaises, modules et meubles annexes dans la proposition.

Préparer la réception

Indiquez destination, accès, passages et étage de réception. Confirmez emballage, manutention et responsabilités de montage pour la commande.

Quel code utiliser dans la demande ?

La source identifie QT-03C24. Ajoutez le plan, le côté d’accès et les dimensions souhaitées pour faire confirmer la configuration.

Peut-on reprendre les dimensions d’un autre visuel ?

Non. Le fabricant indique une taille à personnaliser ; confirmez les dimensions de la composition retenue dans la proposition.
